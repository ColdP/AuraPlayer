Aura Player プライバシーポリシー

施行日：2026年11月10日
最終改定日：2026年11月13日

本プライバシーポリシーは、Aura Player における端末内保存、システム権限、オンライン音楽サービス接続、および歌詞検索に関するデータの取り扱いを説明します。Aura Player 自体にはアカウント登録機能がなく、商用広告や行動分析用の SDK を組み込んでおらず、営利目的のユーザープロファイルも作成しません。オンライン機能を使用した場合にのみ、必要なネットワークリクエストが各提供元へ送信されます。

## 1. ローカル保存とセキュリティ保護

1.1 再生設定、UI・ナビゲーション材質設定、ローカルプレイリスト、再生履歴、お気に入り、カスタム音響プリセット、アートワークおよび音声キャッシュは端末内に保存されます。歌詞共有やプリセット出力で作成した画像、JSON ファイル、QR コードは、ご自身が保存またはシステム共有を実行した際に指定先へのみ出力され、設定やローカル音楽が自動的にクラウドへバックアップされることはありません。

1.2 ログイン認証情報の保護：NetEase Cloud Music にログインした場合、セッション Cookie は Android Keystore で暗号化されたうえで端末内に保存されます。ログアウト、アプリデータの消去、または API サービス URL の変更を行うと、保存されていたログイン状態と認証情報は直ちに削除されます。

## 2. システム権限の用途

2.1 音声メディアの読み取り権限（READ_MEDIA_AUDIO）：端末内の音楽ライブラリをスキャン・表示し、タグ情報や埋め込みアートワークを読み取るために使用します。タグエディターで保存を明示的に確定した場合にのみ、システムの書き込み許可手順に従って該当音声ファイルへ変更を書き込みます。

2.2 ネットワーク・オーディオ・通知権限：INTERNET はオンラインログイン、再生、アートワーク取得、歌詞検索に使用します。MODIFY_AUDIO_SETTINGS は音響処理およびシステムイコライザーの起動に使用します。POST_NOTIFICATIONS および FOREGROUND_SERVICE_MEDIA_PLAYBACK はバックグラウンド再生の維持とダウンロード完了通知の表示に使用します。これらの権限はシステム設定からいつでも管理・取り消しが可能です。

## 3. 通信が発生する場面：NetEase Music と自前 API

3.1 既定の公式ログインと直接接続：既定では、アプリ内で NetEase Cloud Music 公式 HTTPS ログインページ（https://music.163.com/m/login）を開いてログインを行い、リクエストは NetEase の公式サーバーへ直接送信されます。通信内容の扱いは NetEase のプライバシーポリシーおよび利用規約に従います。

3.2 自前 API サービス：高度な接続設定で独自の NeteaseCloudMusicApiEnhanced サービス URL を設定・有効化した場合、再生、検索、プレイリスト、ログインの各リクエストはそのサーバーへ送信されます。ローカルネットワーク上の接続では HTTP が利用可能な一方、公開サーバーには HTTPS が必要です。必ず信頼できるサーバーのみを指定してください。

3.3 オンラインダウンロード：曲またはアルバムアートワークのダウンロードを実行すると、NetEase から取得したリソース URL が Android のシステムダウンローダーへ渡され、取得した音声ファイルは公開ミュージックフォルダー（Music/Aura Player など）に保存されます。

## 4. 通信が発生する場面：オンライン歌詞と外部リンク

4.1 オンライン歌詞検索：歌詞を取得する際、照合のために曲名、アーティスト、アルバム、再生時間などのメタデータを NetEase、QQ Music、Kugou、Kuwo、または LRCLIB へ送信し、オンライン曲 ID を用いて AMLL（GitHub Raw / jsDelivr CDN）または TTML Hub（GitHub Pages）へ字単位歌詞や翻訳歌詞を照会する場合があります。

4.2 ローカル音声ファイルはアップロードしません：上記のオンライン歌詞・アートワーク取得や再生リクエストにおいて、端末内のローカル音声ファイル自体をアップロードすることは一切ありません。

4.3 外部リンク：「このアプリについて」や「設定」画面から作者ホームページ、GitHub リポジトリ、Telegram グループ、QQ グループ、Afdian、または API プロジェクトのリンクを開いた場合、システムブラウザーや外部アプリへ遷移し、その後のデータ処理は各プラットフォームの方針に従います。

## 5. ネットワーク接続メタデータ

5.1 上記の音楽サービス、自前サーバー、リポジトリ、または CDN へリクエストを送信する際、相手先サーバーは通常のインターネット通信の仕組み上、接続元 IP アドレス、アクセス時刻、リクエストパス、クエリパラメーター、User-Agent などの接続情報を受け取ります。本ソフトウェアから IMEI、Android ID、連絡先、インストール済みアプリ一覧などの無関係な情報を送信することはありませんが、接続先サーバーが独自の方針に基づきアクセスログを保存する場合があります。

## 6. データの保持・削除と利用者の管理権

6.1 アプリ設定からカバー画像・曲情報・再生音声のキャッシュをいつでも削除でき、カスタムプリセットの削除、NetEase アカウントからのログアウトによる暗号化セッション消去、あるいはシステム設定でのストレージ／ネットワーク権限の制限により完全オフラインのローカルプレイヤーとして利用することが可能です。

6.2 本ソフトウェアをアンインストールすると、アプリ専用領域の設定、キャッシュ、暗号化認証情報はすべて削除されます。ただし、公開ディレクトリ（Music/Aura Player など）へ保存したダウンロード楽曲、手動でエクスポートしたプリセットや共有画像、および外部サーバー上のアクセス履歴は自動削除されないため、必要に応じて個別に管理してください。

## 7. ポリシーの更新とお問い合わせ

7.1 本ポリシーは機能の変更に合わせて随時更新され、ページ上部に最終改定日を記載します。プライバシーの取り扱いに関するご質問やご提案は、https://github.com/ColdP/AuraPlayer の Issue までお寄せください（公開の場となるため、セッション Cookie や機密性の高い個人情報は記載しないでください）。
