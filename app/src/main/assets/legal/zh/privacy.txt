Aura Player 隐私政策

生效日期：2026年11月10日
最近修订：2026年11月13日

本隐私政策用于说明 Aura Player 在本地存储、系统权限、在线音乐连接及歌词检索方面的数据处理方式。Aura Player 自身不设账号注册体系，不内置商用广告或用户行为统计 SDK，也不会建立商业用途的用户画像；仅在你主动使用或开启联网功能时，应用才会向对应服务方发起必要的网络请求。

## 1. 本地存储与安全保护

1.1 你的播放设置、界面与导航材质配置、本地歌单、播放历史、收藏记录、自定义音效预设、封面与音频缓存均保存在设备本地。你在歌词分享或预设导出中生成的图片、JSON 文件或二维码，仅在你主动保存或调用系统分享时输出至你选定的目标位置或接收方，本软件不会自动将个人数据或本地媒体备份至云端。

1.2 登录凭证保护：当你登录网易云音乐账号时，会话 Cookie 会使用 Android Keystore 硬件或系统级密钥库加密后保存在本机；当你退出登录、清除应用数据或更改服务地址时，本地保存的登录状态与会话凭证会被立即清除。

## 2. 系统权限用途说明

2.1 媒体音频读取权限（READ_MEDIA_AUDIO）：用于扫描和展示设备上的本地音频库、读取歌曲标签与内嵌封面。仅当你在标签编辑器中主动保存修改时，应用才会按系统授权流程将更改写入对应的本地音频文件。

2.2 网络、音频与通知权限：网络权限（INTERNET）用于在线登录、音乐播放、封面获取与在线歌词检索；音频设置权限（MODIFY_AUDIO_SETTINGS）用于音效处理与调用系统均衡器；通知与前台媒体播放权限（POST_NOTIFICATIONS、FOREGROUND_SERVICE_MEDIA_PLAYBACK）用于维持后台播放控制及展示下载完成提示。你可以随时在系统设置中管理或撤销相关权限。

## 3. 联网场景：网易云音乐与自建 API

3.1 默认官方登录与直连：默认情况下，登录流程通过应用内加载网易云音乐官方 HTTPS 登录页（https://music.163.com/m/login）完成，相关请求直接发送至网易云音乐官方服务器，受网易云音乐自身隐私政策与服务条款约束。

3.2 自建 API 服务：如果你在高级连接设置中填写并启用了自建 NeteaseCloudMusicApiEnhanced 服务地址，播放、搜索、歌单及登录请求将发送至你配置的服务器。请注意，本地网络服务可能使用 HTTP 明文通信，公网地址要求使用 HTTPS，请务必仅连接你完全信任的服务。

3.3 在线下载：触发歌曲或专辑封面下载时，应用会将网易云音乐返回的资源地址交由 Android 系统下载器处理，并将完成后的音频文件保存至公共音乐目录（如 Music/Aura Player）。

## 4. 联网场景：在线歌词与外部链接

4.1 在线歌词检索：在播放界面请求在线歌词时，应用会向网易云音乐、QQ 音乐、酷狗音乐、酷我音乐或 LRCLIB 发送歌曲名称、艺术家、专辑与时长等元数据用于匹配，并可能使用在线歌曲 ID 向 AMLL 歌词库（GitHub Raw / jsDelivr CDN）或 TTML Hub（GitHub Pages）检索逐字或翻译歌词。

4.2 本地音频绝不上传：上述任何在线歌词、封面或播放请求都不会上传你设备中的本地音频文件内容。

4.3 外部链接：在“关于”或“设置”页面点击作者主页、GitHub 仓库、Telegram 群组、QQ 群、爱发电或 API 开源项目链接时，将跳转至系统浏览器或对应第三方应用打开，后续的数据处理由相应平台负责。

## 5. 网络连接信息说明

5.1 向上述音乐平台、自建服务、托管仓库或 CDN 发起请求时，接收方服务器按照常规互联网通信机制，可获取请求来源 IP 地址、访问时间、请求路径、查询参数及 User-Agent 等连接元数据。本软件不会主动附带 IMEI、Android ID、通讯录或无关应用清单等设备隐私信息，但第三方服务器可能会依据各自政策记录访问日志。

## 6. 数据保留、清理与你的控制权

6.1 你可以随时在应用设置中清理封面、曲目信息与音频播放缓存，删除自建音效预设，退出网易云账号以清除加密会话，或在系统设置中撤销存储/网络权限以仅在纯离线模式下使用本地播放功能。

6.2 卸载本软件会清除应用私有目录内的设置、缓存与加密凭证；但你主动下载至公共目录（如 Music/Aura Player）的音频文件、手动导出的预设与分享图片，以及第三方服务端留存的访问记录不会随卸载自动删除，如需清理请分别处理。

## 7. 政策更新与联系方式

7.1 本政策会随功能迭代同步更新，并在页面顶部标注最近修订日期。如果你对本软件的隐私处理方式有任何疑问或建议，请前往 https://github.com/ColdP/AuraPlayer 提交 Issue（公开反馈前请勿附带账号 Cookie 或个人隐私信息）。
